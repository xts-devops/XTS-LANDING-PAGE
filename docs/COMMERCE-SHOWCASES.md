# Retail and distribution showcases

Two purpose-named business-system examples extend the existing coffee, construction and school previews. All figures, names and orders are demonstration data, not XTS performance or client claims.

## Retail store and branch management

A warm copper theme with six generated product packshots distinguishes store operations from the coffee POS. Selecting Makati, Quezon City or Cebu City updates product stock, low-stock indicators and transfer suggestions from explicit sample datasets. Transfer drafts need approval and never change on-hand stock. A separate collection handoff completes the preview.

## Warehouse and distribution management

A cool blue control tower follows a 1,248-order sample wave with four storage zones, inbound/outbound docks and destination allocation. Receiving checks precede wave release, which precedes pick/pack verification and dispatch. Future stages can be inspected but their action remains blocked until the preceding checks are recorded. Twelve damaged cartons stay on quality hold throughout.

This is an illustrative workflow, not a full WMS implementation or a throughput benchmark. Sample order counts are chosen to explain allocation across destinations. The control sequence is informed by [Microsoft wave creation and processing](https://learn.microsoft.com/en-us/dynamics365/supply-chain/warehousing/wave-processing) and [packing containers for shipment](https://learn.microsoft.com/en-us/dynamics365/supply-chain/warehousing/packing-containers); these references do not imply a vendor partnership.

## Delivery and interaction

- Append two records to the existing showcase collection and balance the five-card desktop grid as three plus two. Tablet/phone layouts use the established responsive card structure.
- Reuse finite hover workflows and the accessible full-screen viewer. One iframe runs at a time; offscreen/hidden previews clean up. Reduced-motion previews show terminal workflow state without cursor animation.
- No videos, frameworks, per-frame loops or added network services. Product packshots load inside the requested iframe; marketing cards use Astro responsive poster derivatives.
- Editable HTML generator: showcase-ui/commerce.mjs. Local controls: showcase-ui/commerce-actions.js. Shared runtime/style mirrors are generated by buildIndustry.
- Both native screens are 1440 × 900, captured at DPR 2. Phone tables scroll inside a labelled focusable region, not the page.

## Reproduce

Run node showcase-ui/build-screens.mjs then Prettier on generated source/public HTML and scripts. npm run capture:ui captures the full screen contract. For only the additions, run npm run capture:ui -- --only=industry/retail,industry/warehouse. The capture tool validates the complete filename contract before filtering; unknown keys fail. Hotel/property poster capture routes point to their cinematic tour pages.

Run npm run verify; Playwright commerce-operations, industry-demos and system-overviews suites cover native geometry, accessibility, state gates, hover completion and full-screen focus restoration.
