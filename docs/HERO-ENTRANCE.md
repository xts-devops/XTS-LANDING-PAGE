# Global hero and XTS entrance

## Direction

Replace the dashboard collage with a studio-led editorial composition: a direct two-line headline, a sharp engineering image, a numbered four-service index and the existing approved proof points. Keep photography inside a clear frame, with no blurred background panel or moving camera. On small screens, retain the same story with two-column capability links and readable CTAs.

Copy reflects the user's confirmed international team and global client direction. Keep the Philippines base, use “globally” instead of “abroad”, and do not invent offices, countries, team sizes or delivery results.

## Entrance sequence

1. First homepage entry in a tab session, without a section hash and with normal motion: show the supplied mark, XTS and XZEN TECH SOLUTIONS.
2. Reveal Engineer / Build / Connect and a short accent line; this is a brand introduction, not a real loading meter. No percentages or fake system checks.
3. Fade into the already-rendered hero after approximately 0.85 seconds. Never await a network request, image, font or animation engine.
4. Keep it off on subsequent visits/reloads in the same session. Store only a functional session flag, no personal data.

Skip intro, Escape, Tab, Enter, wheel or touch dismiss it. Reduced motion suppresses it entirely, including a live preference change. Hash links and service pages bypass it. No-JS and storage-unavailable visitors see the page immediately. A 1.1-second head-script timeout removes the overlay even if the deferred UI controller fails. The page is never inert or scroll-locked; keyboard navigation dismisses the cover before focus moves behind it.

Only transform, opacity and clip-path animate. There is no additional library, audio, video or render-blocking asset. The hero image itself is never opacity-delayed. Prefer a responsive WebP for its decode cost, and preload the local body font alongside the display font. Preserve no-JS readability and the existing scroll-offset behavior.
