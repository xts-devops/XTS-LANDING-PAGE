## Entrance sequence

1. First homepage entry in a tab session, without a section hash and with normal motion: show the supplied mark, XTS and XZEN TECH SOLUTIONS.
2. Assemble three clipped regions of the supplied logo while fine connection traces converge. A flattened horizon halo and two finite light passes add depth. Reveal the XTS wordmark as one fluid masked movement, then the full name. These are decorative connections, not real system status.
3. Reveal Engineer / Build / Connect and the closing line, then dissolve the whole composition into the rendered hero with a small upward release. The finite sequence lasts approximately 2.9 seconds. Never await a network request, image, font or animation engine.
4. Keep it off on subsequent visits/reloads in the same session. The functional session key is versioned to v3 so existing tabs can see the new introduction once. Store no personal data.

Skip intro, Escape, Tab, Enter, wheel or touch dismiss it. Reduced motion suppresses it entirely, including a live preference change. Hash links and service pages bypass it. No-JS and storage-unavailable visitors see the page immediately. A 3.4-second head-script timeout removes the overlay even if the deferred UI controller fails. The page is never inert or scroll-locked; keyboard navigation dismisses the cover before focus moves behind it.

Only transform, opacity and clip-path animate. There is no additional library, audio, video or render-blocking asset. The hero image itself is never opacity-delayed. Prefer a responsive WebP for its decode cost, and preload the local body font alongside the display font. Preserve no-JS readability and the existing scroll-offset behavior.
